1. Executive Summary & Solution Architecture

The Chandra Shekhar Azad Park Digital Heritage & Visitor Platform is an independent, production-grade tourism and cultural preservation portal for the historic 133-acre sanctuary in Prayagraj, Uttar Pradesh. It combines real-time ambient telemetry, interactive isometric 3D mapping, dual-language audio chronicles, digital pass issuance with cryptographic QR tokens, and gatekeeper verification desks.

Core Architectural Philosophy: Zero external frameworks (Vanilla HTML/CSS/ES6+), extreme mobile responsiveness (zero horizontal scroll down to 320px), client-side offline resilience with Service Workers, and low-latency serverless API execution on Vercel Edge networks.

2. Complete End-to-End User Flow (Visitor Journey)

The platform facilitates a seamless end-to-end journey from online pre-visit planning to on-site exploration and post-visit feedback.

1

Discovery & Telemetry

Visitor lands on portal. System assesses live IST clock, park gate open/close status, and Prayagraj ambient AQI & temperature.

2

3D Miniature Map

Visitor enters the interactive 3D map, filters landmarks by category, inspects points of interest via bottom sheets, and triggers audio guides.

3

Audio Chronicle

User listens to the narration of Chandra Shekhar Azad's 1931 martyrdom battle in English or Hindi with synchronized audio visualizer.

4

Digital Pass Booking

Selects pass category (General, Morning Walker, Museum, Camera), calculates fees dynamically, and generates verified E-Pass with QR code.

5

Gate Verification

At park gates (Gate 1 to 4), staff scans pass QR or enters reference code into the Staff Desk modal for cryptographic authentication.

6

Feedback Pulse

Visitor submits 1-click sentiment rating and suggestion stored into the public review ledger.

5. REST API Architecture & Endpoints

The server exposes lightweight JSON endpoints designed for instant execution on Node.js and Vercel Serverless Functions.

Endpoint Method Parameters Description
/api/park/info GET None Retrieves metadata, opening hours, gate notices, and emergency contacts
/api/attractions GET ?category=... Lists all monuments, pavilions, library, museum, and coordinates
/api/events GET None Returns community yoga, heritage walks, and horticultural exhibitions
/api/reviews GET / POST JSON: author, rating, city, text Reads visitor guestbook and accepts verified guestbook reviews
/api/feedback GET / POST JSON: sentiment, suggestion, category Aggregates visitor sentiment metrics (great, good, okay, needs-improvement)
/api/tickets/book POST JSON: name, email, date, ticketType, quantity Issues verifiable digital E-Pass with reference number and QR payload
/api/tickets/verify/:ref GET Path: ref Security verification endpoint validating ticket authenticity and entry status
/api/health GET None System health, uptime, and server timestamp check

7. Security, Privacy & Performance Audits

  • Zero Secrets in Version Control: Audited .gitignore preventing tracking of .env, private keys, database URLs, deployment tokens, and temporary files.
  • Input Sanitization: Form inputs for bookings, reviews, and pulse suggestions are sanitized against XSS attacks.
  • Responsive Resilience: Verified zero horizontal canvas overflow across all standard mobile and desktop viewports (320px, 375px, 390px, 768px, 1024px, 1440px).
  • Offline Survivability: Service Worker caches essential assets for offline reading and wayfinding.
